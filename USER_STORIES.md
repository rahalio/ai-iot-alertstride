# AlertStride — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Floor nurse / night supervisor

- As a night supervisor, I want an immediate alert when a fall pattern is detected, so I can reach the resident before a long lie.
- As a nurse, I want to acknowledge or escalate an alert, so the system knows the event is being handled.
- As a nurse, I want “device not worn” warnings, so I do not assume safety from silence.

### Clinical risk manager

- As a risk manager, I want false-alarm and miss metrics by wing, so I can tune sensitivity without guessing.
- As a risk manager, I want immutable alert timelines for incident review after a hospitalization.

### Resident / family (consenting party)

- As a family member, I want clear consent language that monitoring is for fall safety, not lifestyle tracking.
- As a resident, I want an easy way to pause monitoring with staff awareness, so dignity is preserved during private activities under policy.

### Biomedical / IT

- As biomedical staff, I want device registry and battery health, so dead wearables do not create blind spots.
- As IT, I want streaming pipeline health dashboards, so model uptime is operationalized.

### Compliance officer

- As compliance, I want retention and access controls on motion streams and alerts aligned to care-home policy.
- As compliance, I want evidence that production model versions were clinically approved.
